# 记忆黑洞 🕳️

> 一个纯本地的「万物收纳盒」——随手记，随时找。**不上云、不联网，你的隐私 100% 属于你自己。**

你有没有这样的经历：
- 随手记了一句灵感，过两天翻不到了
- 拍了一张照片想留着，不知道存哪
- 收到一个文件，想分类归档又嫌麻烦

别担心——丢进黑洞就好。

---

## 📦 我能用它做什么？

一句话、一张图、一段录音、一个文件……所有你想保留下来的东西，全都可以丢进记忆黑洞。存好了之后，想找的时候用关键词一搜就出来。

### 怎么开始？

1. 从右侧 **Releases** 页下载最新版本安装
2. 打开后 **设一个访问密码**（防止别人偷看你的记忆）
3. 点「**新增记忆**」开始往里丢东西

你可以存这些类型：

| 类型 | 怎么存 |
|---|---|
| ✏️ **文字** | 直接输入一段话 / 笔记（支持 Markdown 渲染） |
| 🔗 **链接** | 输入网址，双击预览直接打开 |
| 🖼️ **图片** | 选一张照片或截图 |
| 🎵 **音频** | 录一段语音或收藏一首歌 |
| 🎬 **视频** | 存一段小视频 |
| 📁 **文件** | 任何电脑上的文件 |

### 想找的时候？

在「探索记忆」页输入关键词，黑洞就会把相关记忆吐出来：
- 文字的内容**全文搜索**
- 图片、音频、视频、文件靠 **文件名 + 标签 + 备注** 搜索

找到后双击就能**预览**，还能**编辑内容**或**打开原文件**。

---

## ✨ 它好在哪？

- 🔍 **全文搜索**——中文/英文关键词都支持，搜索精准可靠
- 🧩 **六种类型都能存**——文字、链接、图片、视频、音频、文件，一个地方装完
- 🏷️ **标签分类**——给记忆打标签，左侧栏按标签过滤浏览
- 📊 **统计面板**——一目了然查看总数、类型分布、占用空间
- 🌌 **好看的黑洞动画**——扔进去、吐出来，超有科技感
- 🔒 **密码保护**——密码只存哈希，不存明文，退出后再进要重新验证
- 💾 **纯本地**——数据存在你电脑上，**永不上传、不联网、无账号**
- 🗂 **媒体文件管理**——≤500MB 文件复制到本地 media 目录，超大文件仅存原始路径
- 🗑️ **回收站**——删除进回收站，可恢复可清空
- 📤 **导出/导入**——JSON 完整备份，换电脑迁移无忧
- ⌨️ **快捷键**——Ctrl+N 新增、Ctrl+F 搜索、Ctrl+W 关闭
- 🖱️ **拖拽添加**——文件拖到窗口直接保存
