# 记忆黑洞 🕳️

> 一个纯本地的「万物收纳盒」——随手记，随时找。**默认不上云、不主动联网，数据由你自己掌控。**

你有没有这样的经历：
- 随手记了一句灵感，过两天翻不到了
- 拍了一张照片想留着，不知道存哪
- 收到一个文件，想分类归档又嫌麻烦

别担心——丢进黑洞就好。

---

## 📦 我能用它做什么？

一句话、一张图、一段录音、一个文件……所有你想保留下来的东西，全都可以丢进记忆黑洞。存好了之后，想找的时候用关键词一搜就出来。

### 怎么开始？

1. 从右侧 **Releases** 页下载最新版本安装
2. 打开后 **设一个访问密码**（防止别人偷看你的记忆）
3. 点「**新增记忆**」开始往里丢东西

你可以存这些类型：

| 类型 | 怎么存 |
|---|---|
| ✏️ **文字** | 直接输入一段话 / 笔记（支持 Markdown 渲染） |
| 🔗 **链接** | 输入网址，双击预览直接打开 |
| 🖼️ **图片** | 选一张照片或截图 |
| 🎵 **音频** | 录一段语音或收藏一首歌 |
| 🎬 **视频** | 存一段小视频 |
| 📁 **文件** | 任何电脑上的文件 |

### 想找的时候？

在「探索记忆」页输入关键词，黑洞就会把相关记忆吐出来：
- 文字的内容**全文搜索**
- 图片、音频、视频、文件靠 **文件名 + 标签 + 备注** 搜索

找到后双击就能**预览**，还能**编辑内容**或**打开原文件**。
- 搜索栏下方会醒目提示当前范围（全局 / 某个标签）
- 图片记忆直接在列表显示缩略图，双击可全屏预览

## 🌟 v3.0 有什么不一样

v3.0 是**全新打磨**的一版，界面和体验做了不少调整：

### 🌀 黑洞视觉
- 粒子改为**正圆轨道**绕黑洞转，越靠近视界运动越快（像被引力拽进去）
- **三种状态的光晕都更鲜亮**了：默认态暖色 / 新增记忆时蓝色 / 搜索命中时红色
- 2.5D 平面视界风格（不是花哨的 3D，看着干净）

### 🔍 搜索更快
- 数据库走 SQLite FTS5 全文索引，**中英文单字和词组都能搜**
- 输入有 300ms 防抖，连续打字不卡
- 列表 UI 虚拟化，几万条记忆也不卡

### 🖼️ 列表看缩略图
- 探索页直接显示图片缩略图（小尺寸 100×100）
- 老图片记忆没缩略图的，会自动回退到图标占位

### 🪟 界面细节
- 主窗口默认 950×500
- 6 个弹窗（新增/密码/编辑/删除/提示/预览）尺寸更合理
- 密码框回车直接确认；确认弹窗回车 / Esc 都能用
- 列表滚轮方向符合 Windows 习惯

### 🛡️ 性能与稳定性
- 大文件（≤900MB）流式分块写入 SQLite，不爆内存
- 黑洞动画每帧渲染优化，CPU 占用低
- 添加文件时自动查重（同名 + 同大小会弹提示）

> 老用户升级：数据库结构兼容，数据无损；缩略图首次访问图片时自动生成。

## ✨ 它好在哪？

- 🔍 **全文搜索**——中文/英文关键词都支持，搜索精准可靠
- 🧩 **六种类型都能存**——文字、链接、图片、视频、音频、文件，一个地方装完
- 🏷️ **标签分类**——给记忆打标签，左侧栏按标签过滤浏览
- 📊 **统计面板**——一目了然查看总数、类型分布、占用空间
- 🔒 **密码保护**——密码只存哈希，不存明文，退出后再进要重新验证
- 💾 **纯本地**——数据存在你电脑上，程序不主动上传、不主动联网
- 🗂 **混合存储**——900MB 内的文件可流式分块存入 SQLite 数据库；超过阈值时改为在 `.memoryblackhole/files` 保存副本，路径与元数据由 SQLite 管理

> v3.0.0 BLOB 阈值为 900MB（十进制），刻意小于 SQLite 默认 `SQLITE_MAX_LENGTH=1,000,000,000` 字节（编译期常量，运行时 PRAGMA 无法提高），避免 1 GB 附近文件触发 `string or blob too big`。超过 900MB 的文件会改为本地副本，行为一致。

> 早期版本数据库启用 WAL 模式与较大的页缓存。**从 v2.1.2 之前升级的用户**，既有 `.memoryblackhole/memory.db` 保留原 `page_size`（通常为 1024 字节），`PRAGMA page_size=4096` 对已存在库是 no-op；如需获得 4 KiB 页，可先备份后删除 `memory.db` 与 `memory.db-wal` / `memory.db-shm` 再启动程序重建（历史数据会丢失）。
- ⌨️ **快捷键**——Ctrl+N 新增、Ctrl+F 搜索、Ctrl+W 关闭
- 🖱️ **拖拽添加**——文件拖到窗口直接保存
